## Сетка возвращается / The grid is back

Return Launchpad 3.6.5 brings the full-screen app grid back to your Mac, with folders, keyboard access and native animations.

### What’s new since v2

- System applications and utilities alongside your installed apps.
- Virtual folders: create, rename, reorder, drag in and out, undo and redo.
- Configurable global shortcut, launch at login, icon size and motion settings.
- Smooth page transitions, animated folder opening and delayed edge navigation during drag.
- Persistent icon caching across all pages and improved drag responsiveness.
- Predictable search transitions, hover highlighting and empty-space dismissal.
- Universal Apple Silicon + Intel DMG, SHA256 checksum, and automated build/release workflow.

### Install

Download **Return-Launchpad-3.6.5-universal.dmg**, open it, and drag the app into Applications. Requires **macOS 15.5+**. The app interface is currently **Russian**. Default shortcut: **Control + Option + Space**.

**Signing:** this release is ad-hoc signed and **not notarized by Apple**. If macOS blocks the first launch and you trust the download, attempt to open it, then use **System Settings → Privacy & Security → Open Anyway**. [Apple’s instructions](https://support.apple.com/en-us/102445).

Download the `.sha256` file beside the DMG to the same directory and run:

```sh
shasum -a 256 -c Return-Launchpad-3.6.5-universal.dmg.sha256
```

For upgrades, quit the running app before replacing it. Updates are manual; app folders are virtual and do not move application bundles.

### По-русски

Вернули привычную сетку, системные приложения, полноценные папки, плавное перетаскивание и настройки горячих клавиш. Раскладка сохраняется, изменения можно отменить через ⌘Z. Интерфейс — на русском, сборка одна для Intel и Apple Silicon.

Перетащите приложение в «Программы». Первый запуск может потребовать подтверждения в «Конфиденциальность и безопасность»: сборка пока без нотарификации Apple. Подробнее — в [инструкции](https://github.com/shorins/return-launchpad/blob/main/README.ru.md).
