## Your language. A new look.

- **English and Russian interface.** Choose System, Русский or English in Settings. System uses Russian when the primary system language is Russian, and English for every other language. The choice is remembered; app labels update immediately.
- **A cleaner menu bar.** Removed the status icon. Open Launchpad from the Dock or with your keyboard shortcut; Settings and Quit remain in the app menu.
- **New violet app icon.** The nine-tile grid from the README now ships as a full macOS icon set for Finder and the Dock.
- **Simpler repository.** Kept both READMEs, removed internal Russian engineering notes from the published source and removed their README links.

### Install

Download **Return-Launchpad-3.7.0-universal.dmg**, quit the old app, and drag the new one into Applications. Requires **macOS 15.5+**, Apple Silicon or Intel. Default shortcut: **Control + Option + Space**. Existing folders and layout are preserved.

This release is ad-hoc signed and **not notarized by Apple**. If macOS blocks the first launch and you trust the download, try opening it, then use **System Settings → Privacy & Security → Open Anyway**. [Apple’s instructions](https://support.apple.com/en-us/102445).

Put the checksum file beside the DMG and verify:

```sh
shasum -a 256 -c Return-Launchpad-3.7.0-universal.dmg.sha256
```
