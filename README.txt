Return Launchpad

Install: drag Return Launchpad.app into Applications and open it.
Show / hide: Control + Option + Space (customizable in Settings).
Settings: Command + comma. Quit: Command + Q.
Requires macOS 15.5+. Universal Apple Silicon + Intel build.
Language: System, Русский or English in Settings. System uses Russian for a
Russian system language, English otherwise. Reopen from the Dock or shortcut;
there is no menu bar status icon.

This build is ad-hoc signed, not notarized by Apple. If macOS blocks the first
launch and you trust the download, try opening it, then use System Settings >
Privacy & Security > Open Anyway. Do not disable Gatekeeper system-wide.
https://support.apple.com/en-us/102445

Установка: перетащите приложение в «Программы» и откройте его.
Control + Option + Пробел открывает и скрывает лаунчер.
Настройки: Command + запятая. Завершить: Command + Q.
Поиск: ввод названия, стрелки, Enter. Без запроса стрелки листают страницы.
Создать папку: задержите иконку над центром другой и отпустите после подсветки.
Извлечь из папки: перетащите в подсвеченную зону возврата на главный экран.
Command + Z отменяет изменение. Escape возвращает назад или скрывает окно.
Для личной ~/Applications: настройки > «Добавить папку приложений…».
